# Watcom Health & Beauty Academy

A Next.js learning portal for the Watcom Health & Beauty Academy. The app keeps the brand styling and teaching flow while using a fully local demo authentication flow.

## Features

- Student login using a local dummy account
- Course catalogue and detail pages
- Lesson viewing flow
- Quiz and certificate logic
- Dashboard with protected access

## Development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Then open http://localhost:3000.
